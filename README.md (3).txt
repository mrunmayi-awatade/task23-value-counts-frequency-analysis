# Task 23 - Value Counts and Frequency Analysis

## Overview
This task demonstrates how to analyze categorical data using Pandas.

## Topics Covered
- Counting category frequencies using `value_counts()`
- Analyzing departments, gender, cities, and education
- Calculating relative frequencies
- Calculating frequency percentages
- Including missing values in counts
- Finding the top two most frequent categories
- Identifying unique categories

## Tools Used
- Python
- Pandas
- Jupyter Notebook

## File Included
- task23_value_counts_frequency_analysis.ipynb

## Outcome
Learned how to calculate category frequencies and analyze categorical data using Pandas.
